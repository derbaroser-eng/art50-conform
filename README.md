## Why I made this

Two teams showed me a marking policy. Neither showed me evidence. So I ran the check
myself: I embedded the IPTC `trainedAlgorithmicMedia` XMP block in a 64x64 PNG and the
file went from 161 to 974 bytes — the verifier reported it marked. One ordinary
re-encode brought it back to 161 bytes. The mark was gone.

That gap is what this report measures. Not the policy. The file, after a real re-encode.
